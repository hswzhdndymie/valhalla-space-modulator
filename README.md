## Overview

Valhalla Space Modulator creates classic and extreme flanging, phasing, and through-zero flanging effects through carefully designed modulated delay lines.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Valhalla Space Modulator** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Through-Zero** | True through-zero flanging for the classic jet-plane flanger sound |
| **11 Algorithms** | Multiple flanging and phasing algorithm variants |
| **Barberpole Flange** | Continuously rising or falling flange sweep with no direction reset |
| **Free Plugin** | Available as a free download from Valhalla DSP |
